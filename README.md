A tiny program that writes one comedy patch note for a bug in real life: a sneeze wiping the short-term memory buffer mid-sentence, forcing the speaker to reboot the conversation. It writes exactly that one line, nothing else, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
